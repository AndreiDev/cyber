CYBERSECURITY FLUENCY LIBRARY

Two pages, two altitudes

A learning library on the security craft, for someone who can program but is new to security. It reads at two levels: the Field Map, a standalone view of the whole landscape, and the Codex, thirty real cases that each teach one attack start to finish.

Start with the Field Map’s Foundations section. The detection rules, and two longer worked methods (building a detection end to end, and emulating an attacker to test it), live inside the codex cards.

🗺️ The Field Map

The high-level view, complete on its own — twelve foundational building blocks, the attack lifecycle (the 15 stages of an intrusion in MITRE ATT&CK, the industry’s shared catalogue of attacker behaviour), the eleven attack surfaces, every product category (what it does, what it sees, where it fails), the disciplines, the adversaries, and the shared frameworks. 🛰️ Attack → Defense Codex

30 real cases from 2014 to 2025, each a short course: concepts first, the story in plain language, the attack step by step with the attacker’s reasoning and the trace each step leaves, the defense with reasoning, detection rules you can run (in the standard rule formats: Sigma for logs, YARA for files, KQL for Microsoft’s security tools, Falco for containers; or the honest alternative where no rule can work), the real outcome, lessons, and a self-check. Filterable by attack surface, the part of an organisation the attack came through (identity, cloud, supply chain and eight more).

🔁 Inside case 10 — the blue loop

How a detection engineer builds one detection end to end, using Kerberoasting (a classic attack that cracks Windows service-account passwords offline) as the example: hypothesis → check telemetry → emulate → author → validate → tune → measure → document → maintain.

🟣 Inside case 12 — the red / purple loop

The attacker’s side of the same loop: an authorized red team imitates a real adversary and tries to evade detection, every concept paired with its defensive counter, converging on purple teaming (attackers and defenders working side by side to find and close detection gaps).

ATT&CK Navigator layers (JSON, not web pages). MITRE ATT&CK is the public catalogue of attacker techniques that every codex case is tagged with, and the Navigator is MITRE’s free web tool that draws that catalogue as a grid. These layer files colour the grid by how many of the 30 cases use each technique; there are three because enterprise IT, mobile and industrial control systems (ICS) are separate ATT&CK catalogues: attack-navigator-enterprise.json, -mobile.json, -ics.json. Import them at mitre-attack.github.io/attack-navigator via Open Existing Layer → Upload from local to see technique coverage as a heatmap. The AI cases map to MITRE ATLAS, MITRE’s equivalent catalogue for attacks on AI systems, instead; ATLAS is not a Navigator domain, so those techniques are listed in a plain reference file, atlas-coverage-ai.json.
